### What I work on

I build evaluation, observability, and red-teaming pipelines for LLM-based agents —
mostly around a fictional "Trailhead Travel" support bot I use as a testbed for these tools.

- 🧪 **[trailhead-travel-agent-eval](https://github.com/danteprz9621/trailhead-travel-agent-eval)**
  LLM-agent quality suite (single-turn Q&A, multi-turn chat, RAG) using DeepEval —
  correctness, safety, and hallucination metrics scored by a local judge model.

- 📚 **[trailhead-travel-rag-eval](https://github.com/danteprz9621/trailhead-travel-rag-eval)**
  RAG-pipeline evaluation using Ragas — faithfulness, context precision/recall,
  and answer relevancy, with noise-aware CI thresholds.

- 📈 **[trailhead-travel-observability](https://github.com/danteprz9621/trailhead-travel-observability)**
  Tracing and CI regression gating for an LLM agent using LangSmith —
  versioned eval datasets, a GitHub Actions prompt-regression gate, and drift monitoring.

- 🛡️ **[trailhead-travel-red-team](https://github.com/danteprz9621/trailhead-travel-red-team)**
  Automated red-teaming and safety layering for a RAG agent — Promptfoo attack generation,
  Guardrails AI validation, Llama Guard classification, before/after break-rate comparison.

🔭 Currently building out UI/E2E test automation projects with Selenium and Playwright — stay tuned.
